# Map tiles

Fill-in minimap tiles for maps that ArenaNet's tile service
(`tiles.guildwars2.com`) is missing or renders poorly. Pie UI fetches these
instead of ANet's for the affected regions; every other map still comes from
ANet. Layout is the standard `{continent}/{floor}/{zoom}/{x}/{y}.jpg`.

- **`1/1/`** — Eternity's Garden (ANet ships blank/low-detail tiles here).
  Tiles by [that_shaman](https://twitter.com/that_shaman), via the
  [maps.gw2.io](https://maps.gw2.io) tile service.
- **`2/-31/`** — Mistlock Sanctuary (no ANet tiles at all). Sliced from the
  [Guild Wars 2 Wiki](https://wiki.guildwars2.com/wiki/Mistlock_Sanctuary) map render.

Guild Wars 2 map imagery © ArenaNet.
